# Utility Scripts

这个目录包含辅助工具脚本。

## 工具列表

### Halcon相关
- `fix_halcon_env.py` - Halcon环境修复工具
- `fix_halcon_roi_v2.py` - Halcon ROI修复工具 (v2)
- `halcon_methods_snippet.py` - Halcon方法代码片段

### 诊断工具
- `diagnose_path.py` - 路径诊断工具
- `repair_ui.py` - UI修复工具

## 使用方法

从项目根目录运行：

```bash
# 例如：运行路径诊断
python scripts/utils/diagnose_path.py
```
